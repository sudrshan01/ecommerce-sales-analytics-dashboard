# E-Commerce Sales Analytics Dashboard

## 📊 Project Overview

The **E-Commerce Sales Analytics Dashboard** is an end-to-end data analytics and business intelligence project built using **Python, Excel, and Tableau Public**.

The project analyzes the **Superstore Sales Dataset** to understand sales performance, profitability, customer behavior, regional performance, product performance, and sales trends.

The goal is to transform raw sales data into meaningful business insights using data analysis, visualization, and interactive dashboards.

The project includes:

* Python-based data analysis
* Excel-based dashboard and analysis
* Interactive Tableau Public dashboard
* KPI analysis
* Sales and profit analysis
* Customer and product analysis
* Regional and category performance analysis

---

## 🎯 Project Objectives

* Analyze overall sales and profit performance.
* Track important business KPIs.
* Identify top-performing products.
* Analyze sales performance across regions.
* Compare sales across product categories.

* Understand customer purchasing behavior.

# 📌 Tableau Dashboard

An interactive **E-Commerce Sales Analytics Dashboard** was developed using **Tableau Public**.

The dashboard provides a high-level overview of business performance and allows users to explore the data using interactive filters.

## 📊 Tableau KPI Cards

The dashboard includes the following key performance indicators:

* **Total Sales**
* **Total Orders**
* **Total Profit**
* **Average Order Value**
* **Total Customers**

These KPIs provide a quick overview of overall business performance.

---

## 📈 Tableau Visualizations

The Tableau dashboard contains the following visualizations:

### 1. Monthly Sales Trend

A line chart showing sales performance over time.

**Purpose:**

* Identify sales trends.
* Observe monthly fluctuations.
* Understand overall sales growth patterns.

### 2. Sales by Region

A horizontal bar chart comparing sales performance across regions.

**Purpose:**

* Identify high-performing regions.
* Compare regional sales contribution.
* Understand geographical sales performance.

### 3. Sales by Category

A bar chart comparing sales across product categories.

**Purpose:**

* Identify the strongest product categories.
* Compare category-level revenue.
* Understand category contribution to total sales.

### 4. Top 10 Products by Sales

A horizontal bar chart showing the top 10 products based on sales.

**Purpose:**

* Identify best-selling products.
* Understand which products contribute the most revenue.
* Support product performance analysis.

---

# 🎛️ Interactive Tableau Filters

The dashboard includes interactive filters for:

* **Region**
* **Category**
* **Date**

These filters allow users to analyze the dashboard dynamically.

For example, selecting a specific region updates the relevant KPIs and visualizations to provide a focused view of that region's performance.
